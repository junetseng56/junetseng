# June Tseng — JB Real Estate Agent

A responsive, single-page website with inline CSS and JavaScript.

Open `index.html` in a browser. The portrait is embedded in the HTML; the property photo loads from the NextSix image host with a coloured fallback.

## Deploy to Vercel

Import this GitHub repository into Vercel. Select **Other** as the framework, keep the root directory as `./`, and leave the build command empty. The included `vercel.json` configures the static output. Commits to `main` will deploy automatically after the repository is linked.
